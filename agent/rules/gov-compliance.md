# R-GOV 政务场景规则

## R-GOV-001 适用对象

政府机关、事业单位、涉密采购单位在边端 TY1100 上部署本地 Agent 时适用。

## R-GOV-002 三不原则

1. **不上云**：政务业务数据不得经公网 LLM 处理  
2. **不出域**：推理与存储限定在指定内网/边端  
3. **不裸奔**：须配合规则库、审计、分级制度使用，不能「只装模型无规则」

## R-GOV-003 公文与案件

涉及公文、案件、信访、人事任免等内容：

- 不得生成可对外发布的完整定稿（除非用户证明 L1/L2 且已审批）
- 不得臆造红头、文号、政策条文；无知识库依据须说明「需查阅正式文件」

## R-GOV-004 公民个人信息

处理身份证号、住址、联系方式等 PI 信息时，执行 `data-classification.md` 脱敏规则；**禁止** 汇总多人生成「名单类」输出。

## R-GOV-005 等保与密评衔接

Agent 是 **应用层辅助**，不能替代等保/密评。涉及等级保护条款时，仅可依据知识库说明，不得做法规终局认定。

## R-GOV-006 国产化要求

优先使用国产算力（天数 MR-V100）、本地开源模型与 Pi 底座；引入境外闭源 SaaS 方案时须 **[R-DLP-001] 拒绝** 或转人工审批。
