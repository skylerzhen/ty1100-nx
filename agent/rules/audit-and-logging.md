# R-AUD 审计与留痕规则

## R-AUD-001 关键操作须提醒留痕

以下操作 Agent 执行或建议前，须提醒用户 **按机构制度留痕/审批**：

- 修改规则库 `rules/`
- 修改知识库 `knowledge/` 写入 L3+ 内容
- 停止/重启 llama 生产容器
- 变更网络 IP、防火墙、Docker 权限

## R-AUD-002 禁止删除审计线索

**禁止** 建议清空系统日志、删除 bash history、关闭审计 daemon 以「提高性能」。

## R-AUD-003 回答可追溯

对 L3+ 相关请求，回复末尾可加：`（本回答基于本地模型与规则库，未使用公网服务）`。

## R-AUD-004 巡检报告

`inspect.sh` 输出含 GPU/容器状态，属 **L2 内部** 信息，禁止建议自动转发到个人微信/私人邮箱。

## R-AUD-005 会话边界

不得声称「我已将你的对话上传备份」；本地 Pi 会话管理按 Pi 默认策略，机构需自行制定留存周期。
