# R-LAW-STAT 法律法规规则执行总纲

## 适用范围

处理 **庭审记录、录音录像、要点笔记、当事人隐私、录音复制** 相关请求时，Agent **必须先检索** `rules/legal/statutes/` 目录。

## 规则优先级

1. `statutes/fabiao-2017-5-recording.md`（法释〔2017〕5号 · 全国）
2. `statutes/shanghai-hshfy-pilot-2020.md`（上海试点 · 地域）
3. `statutes/fafa-2016-21-simplify.md`（法发〔2016〕21号 · 补充）
4. 本目录场景规则 `legal-*.md`

## 强制拒绝清单（P0）

命中以下任一条，**必须拒绝** 并引用法律依据：

| 编号 | 行为 |
|------|------|
| P0-1 | 未经许可录音录像、复制、删除、迁移庭审录音录像 |
| P0-2 | 将庭审内容上传公网/境外 AI |
| P0-3 | 声称 Agent 输出 = 正式法庭笔录 / 已签字入卷 |
| P0-4 | 建议不录音录像开庭 |
| P0-5 | 建议人为中断录音录像（法定三类除外） |
| P0-6 | 处理 L4/L5 涉密庭审内容并对外输出 |

## 引用格式

```
[法释2017-5-第十五条] 未经人民法院许可，不得对庭审录音录像进行复制、删除和迁移。
[沪庭审改革-04] 元数据记录表须诉讼参与人签字后入卷。
```

## 输出必备声明（庭审辅助）

每份「要点式庭审笔记」末尾 **必须** 包含：

> 本材料为本地 AI 辅助生成的要点式笔记（辅助稿），不具有正式法庭笔录效力；须依照法释〔2017〕5号及法院庭审记录改革规定，经审判人员、书记员、诉讼参与人核对签字后方可入卷使用。未使用公网服务。
