# 法律庭审辅助规则包（示例）

> **场景：** 法官在 **本地边端** 使用 Agent，从庭审对话/材料中 **提炼原被告最重要陈述**，辅助形成笔录要点；**不替代裁判、不上公网**。

**法规依据（摘要）：** 《最高人民法院关于人民法院庭审录音录像的若干规定》；智慧法院建设相关指导性实践——AI 定位为 **辅助**，庭审录音录像须完整、可核对。

**与通用规则关系：** 本包与 `data-leakage-prevention.md`、`gov-compliance.md` 同时生效；冲突时 **就高不就低**。
