# 《关于进一步推进案件繁简分流优化司法资源配置的若干意见》相关条款

**文号：** 法发〔2016〕21号  
**发布：** 最高人民法院

## 法发2016-21-第11条 · 录音录像替代庭审笔录（要点）

（据上海市青浦区人民法院《推进庭审记录改革工作实施细则》引述）

> 本次开庭运用 **全程同步录音录像替代庭审笔录**。

**适用语境：**
- 上海法院在发放出庭通知书、传票时，对 **非简易程序等案件** 的告知内容之一  
- 与法释〔2017〕5号 **第八条**（简易程序 + 当事人同意）配合理解  

**Agent 要求：**
- 向用户说明：替代笔录须符合 **程序类型 + 当事人同意 + 法院告知** 等条件
- 不得笼统说「所有案件都不用笔录」

---

## 法发2016-21 · Agent 一般原则

- 繁简分流目的是 **优化司法资源配置**，不是降低记录质量  
- Agent 辅助应 **提高准确完整记录**，而非减少留痕
