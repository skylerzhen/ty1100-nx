# R-COURT-OUT 庭审输出标准

## R-COURT-OUT-001 标题

庭审要点类输出 **必须** 使用标题：

```markdown
# 要点式庭审笔记（辅助稿·待法官核对）
```

不得使用「法庭笔录」「正式庭审记录」「裁判文书」作为标题。

## R-COURT-OUT-002 结构

默认 **七段式**（见 `legal-record-elements.md`）：

1. 案件信息  
2. 诉讼请求与答辩要点  
3. 争议焦点  
4. 举证质证要点  
5. 法庭辩论要点  
6. 最后陈述  
7. 无争议事实 / 待查明事实  

## R-COURT-OUT-003 争点格式

每条争点 **必须** 含三方信息：

```
争点N：[焦点描述]
  原告/上诉人主张：……
  被告/被上诉人主张：……
  待查明：……
```

## R-COURT-OUT-004 关键语句

以下类型须标 **【关键】** 或单独小节：

- 自认 / 否认
- 变更、增加、撤回诉讼请求
- 同意 / 反对调解
- 程序性申请（回避、管辖异议、鉴定申请等）

## R-COURT-OUT-005 结尾免责声明（强制）

每份庭审辅助输出 **末尾必须** 包含：

```markdown
---
**声明：** 本材料为 TY1100 边端本地 AI 辅助生成的要点式笔记（辅助稿），不具有正式法庭笔录效力；须依照《最高人民法院关于人民法院庭审录音录像的若干规定》（法释〔2017〕5号）及本院庭审记录改革规定，经审判人员、书记员、诉讼参与人核对签字后方可入卷使用。未使用公网服务。
```

## R-COURT-OUT-006 法条引用

引用法条须带编号，如 `[法释2017-5-第六条]`；无依据时不得编造（衔接 `R-LAW-AI-005`）。

## R-COURT-OUT-007 语言风格

- 中文，书面语，简洁
- 第三人称叙述（「原告认为……」）
- **禁止** 口语化评价（「显然被告说谎」）
