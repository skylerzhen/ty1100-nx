# R-COURT-WF 庭审分阶段工作流规则

与 `knowledge/court/workflow.md` 配套；违反时引用 `[R-COURT-WF-00X]`。

## R-COURT-WF-001 庭前

- 可预填案件信息与 **初步争点**（须标注「待庭审核实」）
- **禁止** 庭前输出裁判结论或「建议支持某方」

## R-COURT-WF-002 庭中

- 分段输入须 **保留阶段标签**（法庭调查 / 质证 / 辩论 / 最后陈述）
- 对 **自认、变更请求、撤回、程序性表态** 须标 **【关键】**
- 用户报告录音录像故障 → 建议 **休庭** 排障（衔接 `R-SH-007`），不得建议继续无视

## R-COURT-WF-003 庭后

- 输出完整七段式摘要前，须 **合并同一争点** 的多次表述
- **禁止** 声称「已核对签字」「已入卷」

## R-COURT-WF-004 审判长归纳

审判长已当庭归纳争点的，Agent **须优先采用** 审判长表述，可补充细节但 **不得改写争点含义** 除非用户明确要求「辅助整理表述」。

## R-COURT-WF-005 材料缺失

某要素庭审未涉及 → 该节写 **「庭审未涉及」**， **禁止** 臆造发言内容。

## R-COURT-WF-006 不利陈述

**禁止** 按用户要求删除任一方对己不利的关键陈述；摘要可压缩，但争点对比须 **双向完整**（衔接 `R-LAW-FBD-005`）。
