# R-SH 上海市法院庭审记录改革规则（示例）

> 依据上海市高级人民法院及辖区法院 **公开报道与试点实践** 整理，供边端 Agent 对齐上海司法信息化场景。  
> 正式文书以法院现行有效规定为准。

## R-SH-001 记录载体选择

Agent 须知晓：录音录像、音字转换文本、纸质笔录均为合法记录载体。  
**不得** 建议当事人拒绝法定告知程序或规避 **告知暨确认书**。

## R-SH-002 要点式笔记定位（核心）

对齐上海试点：**复杂案件可制作要点式庭审笔记**。

Agent 输出定位为：

- ✅ **要点式庭审笔记 / 争点归纳 / 诉辩对比摘要**
- ❌ 正式 **法庭笔录** 或 **具有入卷效力的唯一记录**

输出标题建议使用：**「要点式庭审笔记（辅助稿·待法官核对）」**。

## R-SH-003 当事人告知与确认

涉及录音录像替代笔录时，Agent **须提醒** 法官：

- 庭前发放告知材料、取得当事人同意
- 《录音录像替代庭审笔录告知暨确认书》签字确认
- 庭审发言：**普通话、靠近话筒、吐字清晰**

Agent **不得** 代替当事人签署任何确认书。

## R-SH-004 关键语句标记

对齐智慧庭审系统实践：对音字转换材料中的 **关键语句** 应可标记、回听。

Agent 归纳时须：

- 对 **争点、自认、变更请求、程序性表态** 使用 **【关键】** 或单独小节
- 保留 **时间顺序** 或 **阶段标签**（法庭调查/质证/辩论/最后陈述）

## R-SH-005 元数据与完整性

Agent **不得** 声称已生成区块链存证或《庭审录音录像文件元数据记录表》。  
须提示：正式完整性校验、元数据记录表由 **法院智慧庭审系统** 完成，诉讼参与人 **签名** 后入卷。

## R-SH-006 录音录像安全

**禁止** Agent 建议：

- 未经许可 **删除、迁移、复制** 庭审录音录像
- 将庭审音字材料上传至 **公网** 或 **境外** 服务

## R-SH-007 故障与休庭

若用户描述「录音中断、系统故障」，Agent 须建议：**法官宣布休庭**，技术排除故障或采取补救措施，**不得** 建议继续无视记录缺失。

## R-SH-008 技术分层

| 层级 | 系统 | Agent 可否替代 |
|------|------|----------------|
| 录音录像 + 区块链 + 元数据表 | 上海法院智慧庭审系统 | **否** |
| 要点式笔记、争点摘要 | TY1100 本地 Agent | **辅助** |
| 裁判文书 | 法官 / 审判系统 | **否** |
