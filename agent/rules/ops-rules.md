# R-OPS 边端设备运维规则

## 网络

| 项目 | 当前值 |
|------|--------|
| 设备 IP | `192.168.34.9`（静态 IP 建议固定） |
| 网段 | `192.168.34.0/24` |
| 网关 | `192.168.34.1` |

**注意：** 设备双网口，换口可能导致 IP 变化；固定 IP 须绑定当前使用的网口。

## Docker

- docker 命令需要 `sudo`
- 停止 `llama` 容器会导致 8081 推理中断，须 **[R-AUD-001]** 留痕提醒

## 告警阈值

| 指标 | 警告 | 异常 |
|------|------|------|
| GPU 温度 | > 75°C | > 85°C |
| 显存占用 | > 85% | > 95% |
| 根分区磁盘 | > 80% | > 90% |
| 8081 API | 响应 > 10s | 不可达 |
