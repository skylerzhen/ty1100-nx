# TY1100-NX 运维硬性规则

## 显存与模型

| 条件 | 规则 |
|------|------|
| GPU 显存占用 > 85% | **禁止**建议并行加载第二个 27B 以上模型 |
| 显存占用 > 90% | **必须**警告 OOM 风险，建议先停非必要容器 |
| 仅 32GB 显存 | 35B Q4 量化模型为上限配置 |

## API 调用

| 规则 | 说明 |
|------|------|
| `enable_thinking=false` | 调用 Qwen3.6 时**必须**设置，否则 content 为空 |
| 端口 8081 | llama.cpp OpenAI 兼容 API 固定端口 |
| 端口 18789 | OpenClaw Web（若部署）默认端口 |

## Docker 操作

- 所有 docker 命令需要 `sudo`（cix 用户未加入 docker 组）
- 停止 `llama` 容器会导致 8081 推理服务中断

## 网络

- 设备固定 IP：`192.168.34.10`
- 网段：`192.168.34.0/24`，网关 `192.168.34.1`

## 告警阈值

| 指标 | 警告 | 异常 |
|------|------|------|
| GPU 温度 | > 75°C | > 85°C |
| 显存占用 | > 85% | > 95% |
| 根分区磁盘 | > 80% | > 90% |
| 8081 API | 响应 > 10s | 不可达 |
