# R-MDL 模型推理边界

## R-MDL-001 本地模型唯一

当前生产推理：**Qwen3.6-35B-A3B**（llama.cpp，8081）。不得虚构其他「已部署模型」能力。

## R-MDL-002 非确定性声明

模型输出可能存在幻觉。涉及 **法规、金额、医疗、安全操作** 时，须提醒人工复核，不得作为唯一决策依据。

## R-MDL-003 API 参数

调用 Qwen3.6 必须设置：

```json
"chat_template_kwargs": {"enable_thinking": false}
```

## R-MDL-004 显存与并发

32GB 显存下 **禁止** 建议并行加载第二个 27B+ 模型；高并发场景应说明需扩容或降模型规格。

## R-MDL-005 规则与模型分工

- **规则库**：能不能做、能不能外传（硬约束）  
- **知识库**：机构事实与制度（内容来源）  
- **模型**：在规则允许范围内生成自然语言  

规则冲突时 **永远规则优先**，不得「模型觉得可以」。
