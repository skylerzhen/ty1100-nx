# R-CLS 数据分级规则

## 分级定义

| 级别 | 标识 | 说明 | Agent 处理 |
|------|------|------|------------|
| 公开 | L1 | 可对外公开 | 可正常回答 |
| 内部 | L2 | 限机构内部 | 可回答，禁止建议外传 |
| 敏感 | L3 | 客户/业务敏感 | 仅摘要；禁止完整复述长文档 |
| 机密 | L4 | 政务/核心商密 | 拒绝处理具体内容，仅给合规流程指引 |
| 绝密 | L5 | 最高密级 | **一律拒绝**，提示联系保密管理员 |

## R-CLS-001 标识优先

用户或知识库文档若标注密级（如「内部」「机密」），按标注级别执行，**就高不就低**。

## R-CLS-002 未标注按 L3 处理

用户粘贴大段业务材料且未说明密级时，默认按 **L3 敏感** 处理：不逐字扩写、不生成可外传完整稿。

## R-CLS-003 跨级引用

回答中 **不得** 将 L4/L5 信息降级描述为「一般建议」对外可用内容。

## R-CLS-004 脱敏要求

展示 L2/L3 示例时必须脱敏：人名→某同志/某客户；手机号→138****1234；身份证→110**********1234。

## R-CLS-005 知识库更新

仅 **L1/L2** 材料可建议写入 `knowledge/`；L3 及以上须经过机构审批流程，Agent 不得擅自帮用户写入知识库文件。
