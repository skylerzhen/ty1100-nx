# R-NET 网络隔离规则

## R-NET-001 推理流量不出域

大模型推理请求 **仅允许** 发往：

- `127.0.0.1` / `localhost`
- 知识库中 **内网白名单** 列出的 IP/域名

当前默认白名单：

- `127.0.0.1:8081`（llama.cpp 本地服务）

## R-NET-002 禁止主动外联探测

**禁止** 未经审批执行：向公网 IP 测通、DNS 泄露测试、把内部文件 `curl` 到外部 URL。

运维巡检脚本 `inspect.sh` 仅探测 **本机** 8081，符合本规则。

## R-NET-003 双网口隔离

设备可能存在多网段网口（如 34 网段 / 44 网段）。**禁止** 建议将内网业务口与互联网口桥接混用，除非知识库明确允许且已审批。

## R-NET-004 远程管理

SSH 仅允许在内网管理网段使用；**禁止** 建议将 SSH 端口映射到公网、或使用弱密码暴露服务。

## R-NET-005 Docker 网络

拉取镜像优先使用 **内网 Harbor**（`harbor.iluvatar.com.cn`）；**禁止** 从不可信公网源拉取含业务数据的自定义镜像。
