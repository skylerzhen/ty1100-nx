# 庭审辅助场景知识库

> **总入口：** [court/README.md](./court/README.md)  
> **工作流：** [court/workflow.md](./court/workflow.md) · **角色：** [court/roles.md](./court/roles.md) · **输入：** [court/input-guide.md](./court/input-guide.md)

## 场景定义

**用户：** 法官 / 审判辅助人员  
**任务：** 在庭审过程中或庭后，从 **双方陈述、诉辩材料** 中提炼 **最重要、与争点相关** 的内容，形成 **结构化要点**，减轻记录负担。  
**部署：** TY1100-NX 边端本地 Agent + 本地 Qwen 模型，**数据不出法院内网**。

## 与智慧法院实践的关系

| 能力 | 传统/智慧法院 | 本边端 Agent |
|------|----------------|--------------|
| 语音转写 | 法庭语音识别 ASR | 可对接或粘贴转写文本 |
| 要素提取 | 诉辩分析、争点归纳 | `rules/legal/legal-record-elements.md` |
| 笔录生成 | 规整版庭审笔录 | 输出 **要点摘要稿**，须法官核对 |
| AI 定位 | 辅助审判 | **不替代裁判**（见 `legal-ai-boundary.md`） |

## 典型工作流

```
庭前：导入起诉状/答辩状要点（L3 脱敏测试）
  ↓
庭中/庭后：粘贴庭审转写文本 或 分段输入
  ↓
Agent：按 legal-record-elements 输出结构化摘要
  ↓
法官：核对、修正、并入正式笔录系统
```

## 演示用例（虚构，仅供测试）

**案由：** 民间借贷纠纷（虚构）  
**原告诉求：** 判令被告偿还本金 10 万元及利息  
**被告答辩：** 已部分清偿，利息约定过高  

**输入 Agent 的示例文本：**

> 原告代理人：被告于2023年1月借款10万元，约定年利率24%，至今未还本息……  
> 被告：认可收到10万元，但已于2023年6月还款3万元，且利息应按LPR四倍计算……

**期望 Agent 输出：** 诉讼请求列表、争点 2～3 条、无争议/有争议事实区分，**不出现「应判谁赢」**。

## 法规参考（知识库级摘要，非正式法律意见）

- 庭审 **应当全程录音录像**（《最高人民法院关于人民法院庭审录音录像的若干规定》第1条）
- 智能语音转换文字经 **核对签字** 后可作法庭笔录使用（同上第6条）
- AI 在司法领域应为 **辅助工具**，裁判责任在法官
