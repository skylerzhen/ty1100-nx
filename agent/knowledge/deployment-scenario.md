# 政务 / 企业私有化部署场景

## 解决什么问题

机构希望在 **内网 / 边端** 使用大模型与 Agent，但面临：

- **不能上公网 LLM**（数据泄露、合规、等保/密评）
- **核心文档不能出境**
- 需要 **可审计、可拒绝、可定制** 的行为边界

TY1100-NX + 本地 Qwen + Pi Agent + **规则库** 即为此场景设计：**算力与数据均在可控域内**。

## 典型客户

| 类型 | 诉求 |
|------|------|
| 政务 | 公文辅助、政策问答、内网办事指南；三不：不上云、不出域、不裸奔 |
| 国企/金融 | 制度问答、运维助手；禁止客户名单/交易数据外传 |
| 制造/能源 | 设备运维、规程查询；工艺参数不出厂区 |

## 架构要点

```
用户 → Pi Agent（规则校验）→ 本地 8081 大模型
         ↑
    rules/ 硬规则（防泄露）
    knowledge/ 机构知识
```

## 演示话术（对外）

> 我们在边端盒子上部署本地大模型，Agent 所有回答先过 **规则库**；涉及外传、公网 API、敏感数据导出会 **自动拒绝**，数据不出域。

## 扩展方向

- 按客户导入 **行业规则包**（政务版、金融版）
- 知识库对接 **内网文档系统**（仍本地检索）
- 审计日志对接 **SIEM / 等保平台**
