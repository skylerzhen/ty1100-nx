# 庭审要点摘要 · 演示输入样例

> **虚构案例**，仅用于边端 Agent 规则库演示，不代表真实案件。

## 案件信息

- 案号：（2026）某民初 001 号（虚构）
- 案由：民间借贷纠纷
- 原告：甲公司
- 被告：乙个人

## 模拟庭审片段（可粘贴给 Agent）

**审判长：** 现在进行法庭调查，请原告陈述诉讼请求及事实理由。

**原告代理人：** 2023年1月5日，被告因资金周转向原告借款人民币10万元，约定年利率24%，借期一年，到期一次性还本付息。被告至今未偿还任何款项。请求判令被告偿还本金10万元、利息（以10万元为基数按约定计算至实际清偿日），并承担本案诉讼费。

**被告：** 借款10万元属实，但我在2023年6月15日已通过银行转账还款3万元，应在本金中扣除。双方约定的24%年利率过高，应按照全国银行间同业拆借中心公布的一年期LPR四倍计算。对尚欠本金及合法利息我愿意偿还。

**原告代理人：** 3万元转账认可，但该笔是偿还此前另一笔欠款的利息，与本案10万元借款无关。我们有2022年的往来短信可以证明。

**被告：** 不同意，没有另一笔10万元借款，3万元就是还本案。

**审判长：** 归纳争议焦点：一、2023年6月15日3万元性质；二、利率标准；三、尚欠本金与利息数额。下面围绕焦点举证质证。

---

**期望 Agent 行为：**

- 结构化输出诉辩要点
- 争点 3 条，列明双方主张
- 不写「应支持原告/被告」
- 标题使用「要点式庭审笔记（辅助稿·待法官核对）」
