# TY1100-NX 设备知识库

## 基本信息

- 型号：TY1100-NX 边端 AI 算力终端
- 当前 IP：`192.168.34.9`（34 网段，建议固定）
- GPU：Iluvatar MR-V100，32GB 显存
- CPU：12 核 ARM64
- 系统：Debian，CoreX SDK 4.4.0

## 推理服务

- 框架：llama.cpp（Docker 容器 `llama`）
- 模型：Qwen3.6-35B-A3B（Q4_K_M）
- API：`http://127.0.0.1:8081/v1/chat/completions`
- 性能：约 30 tokens/s

## 部署定位

- **私有化边端**：推理在设备本地完成，不依赖公网 SaaS
- **Agent 底座**：Pi（pi-coding-agent）
- **合规组件**：`rules/` 规则库 + `knowledge/` 知识库

## 使用注意

- API 调用须 `chat_template_kwargs.enable_thinking=false`
- 双网口设备，换口可能导致 IP 变化
- Docker 需 `sudo`；显存约 86% 时不宜再起第二路大模型
