## 上海改革核心内容（据公开报道）

### 1. 记录方式多元

庭审 **录音录像**、**智能语音识别同步转换文字**、**传统纸质笔录** 均为记录庭审活动的有效载体，可 **视情选择或组合使用**。

当事人 **同意且具备条件** 的，应 **优先** 运用录音录像替代庭审笔录。

### 2. 复杂案件 → 「要点式庭审笔记」

（最高法院报道上海试点）

> 复杂案件的庭审，可以安排书记员 **只制作要点式庭审笔记**，供法官制作裁判文书、庭审活动信息存档等之用。

**与本边端 Agent 的对应关系：**  
TY1100 本地 Agent 可承担 **「要点式归纳 / 争点整理」** 辅助，**不替代** 正式录音录像、音字转换材料及法官审核。

### 3. 技术保障（上海实践）

- **上海法院智慧庭审系统**
- **区块链存证、时间叠加** 保证录音录像真实完整
- 庭审结束自动生成 **《庭审录音录像文件元数据记录表》**，诉讼参与人 **签名** 后入卷
- 音字转换可 **标记关键语句**；支持 **个性化词汇库** 提高识别率（据徐汇法院等公开操作指引）

### 4. 权利保障（闵行法院等基层实践）

- 发放 **《录音录像替代庭审笔录告知暨确认书》**
- 庭审前 **再次签字确认**
- 提醒当事人：**讲普通话、靠近话筒、声音洪亮**
- 录音录像故障 → 法官 **宣布休庭**，技术排除故障

### 5. 安全要求

- **未经法院许可**，任何人不得 **删除、迁移、复制** 庭审录音录像

### 6. 上海知产法院等试点经验

- 试点法庭配备 **庭审录制系统 + 智能庭审系统 + 备份系统**，互相独立、分别存储
- 区块链存证 + 语音识别 + 全程录音录像 **替代书记员庭审记录**

## 边端 Agent 在上海模式下的定位

```
正式层：录音录像 + 音字转换 + 元数据记录表 + 签名入卷  （法院智慧庭审系统）
辅助层：要点式笔记 / 争点归纳 / 诉辩对比摘要           （TY1100 本地 Pi Agent）
```

Agent **不得** 声称替代上海法院智慧庭审系统或已具备同等法律效力。
