# 庭审材料输入指南

## 支持的输入类型

| 类型 | 格式 | 说明 |
|------|------|------|
| ASR 音字转换文本 | 纯文本 / Markdown | 来自智慧庭审系统，优先 |
| 起诉状 / 答辩状摘要 | 结构化 bullet | 庭前预填，避免全文扫描件 |
| 审判长归纳争点 | 原文引用 | 须标注「审判长归纳」 |
| 分段庭审记录 | 带阶段标签 | 见 `workflow.md` |

## 不支持 / 须拒绝的输入请求

- 上传音频 / 视频到 **公网** 转写
- 批量导出整库庭审录音
- 要求 Agent **听实时麦克风**（当前边端仅文本 + 本地模型；实时 ASR 由法庭系统负责）

## 推荐输入模板

```markdown
【案件信息】
案号：（2026）某民初 001 号
案由：民间借贷纠纷
程序：一审

【阶段：法庭调查】
（粘贴 ASR 或人工记录文本）

【阶段：举证质证】
……
```

## 长文本处理

1. **按阶段拆分**，每段不超过模型上下文舒适区（建议单次 < 8000 字中文）
2. 跨段归纳时，Agent 应 **保留阶段标签** 与 **时间顺序**
3. 同一争点多次出现时， **合并** 而非重复罗列

## ASR 文本清洗

Agent 应容忍 ASR 常见噪声，但输出时 **修正明显同音错误** 须谨慎：

- 人名、金额、日期： **保留原文并标注［ASR原文］** 若不确定
- 法律术语：可规范化为常用表述，不改动语义

## 隐私与脱敏

- 测试环境：身份证号、手机号、住址 → 掩码（`rules/legal/legal-party-privacy.md`）
- 生产环境：按法院权限， **禁止** 建议复制到个人 U 盘 / 邮箱
