# 庭审辅助工作流（庭前 · 庭中 · 庭后）

## 总体原则

- 每个阶段输出均为 **辅助稿**，标题含 **「要点式庭审笔记（辅助稿·待法官核对）」**
- 正式录音录像、音字转换、元数据记录表由 **法院智慧庭审系统** 完成
- 边端 Agent 仅处理 **已授权进入本地终端** 的文本材料

---

## 阶段一：庭前准备

### 输入（可选）

| 材料 | 用途 | 密级注意 |
|------|------|----------|
| 起诉状 / 答辩状 **要点摘要**（非全文扫描件优先） | 预填案件信息、诉讼请求 | L3+，禁止外传 |
| 证据目录 **名称与证明目的** | 庭前争点预判 | 不含证据原件导出 |
| 前次庭审要点 | 二审 / 续审衔接 | 须标注来源庭审 |

### Agent 可输出

- 案件信息预填表（案号、案由、当事人、诉讼请求列表）
- **初步争点清单**（标注「待庭审核实」）
- 庭前 **无争议事实** 候选列表

### Agent 不可输出

- 裁判预测、胜诉概率
- 替代 **立案审查** 或 **管辖** 正式结论

---

## 阶段二：庭中（法庭调查 · 质证 · 辩论）

### 输入方式

1. **智慧庭审 ASR 音字转换文本**（复制段落，见 `input-guide.md`）
2. **书记员实时粘贴** 某阶段发言摘要
3. **庭后一次性导入** 完整转写（分段标记阶段）

### 推荐分段标签

```
【法庭调查】
【举证质证】
【法庭辩论】
【最后陈述】
【法官归纳】（如审判长已归纳争点，须准确记录）
```

### Agent 可输出

- 实时或阶段性 **诉辩要点** 更新
- **争议焦点** 动态列表（2～5 条）
- **【关键】** 标记：自认、变更请求、程序性表态、撤回申请等
- 无争议 / 有争议事实分离

### 庭中注意

- 若用户描述 **录音录像中断** → 建议休庭排障（`R-SH-007`）
- 不删改任一方 **不利陈述**（`R-LAW-FBD-005`）

---

## 阶段三：庭后整理

### 输入

- 完整或分段 ASR 文本
- 法官 / 书记员修正意见（「第 3 争点应以……为准」）

### Agent 可输出

- 完整 **七段式庭审要点摘要**（见 `legal-record-elements.md`）
- 供制作裁判文书参考的 **「经审理查明」事实候选**（无争议部分）
- 待查明事实与争点对照表

### 交付边界

- 输出进入 **本院审判系统 / 文书制作流程** 前，须 **审判人员核对**
- Agent 不得声称「已入卷」「已签名确认」

---

## 与上海「复杂案件要点式笔记」的对应

| 上海实践 | 本 Agent 对应动作 |
|----------|-------------------|
| 书记员制作要点式庭审笔记 | 辅助生成争点、诉辩对比、阶段摘要 |
| 录音录像 + 音字转换为主记录 | Agent 不替代；可引用转写文本 |
| 元数据记录表 + 签名入卷 | Agent 不参与；须提示由智慧庭审系统完成 |

---

## 工作流示意

```text
庭前：诉答要点 → 案件信息 + 初步争点（待核实）
         ↓
庭中：ASR 分段 → 阶段性要点 + 【关键】标记
         ↓
庭后：完整转写 → 七段式摘要 → 法官核对 → 审判系统 / 文书
```
