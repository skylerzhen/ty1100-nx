# 庭审术语表（Agent 输出应统一使用）

| 术语 | 含义 | Agent 用法 |
|------|------|------------|
| 法庭调查 | 当事人陈述请求、事实、理由的阶段 | 阶段标签 |
| 举证质证 | 出示证据、质证、法院认证 | 单独小节，记录三性异议要点 |
| 法庭辩论 | 围绕争点发表意见 | 每方 bullet ≤ 5 条 |
| 最后陈述 | 庭审结束前的最终意见 | 各 1～3 句核心意思 |
| 争议焦点 / 争点 | 双方分歧的核心问题 | 2～5 条，含双方主张对比 |
| 诉讼请求 | 原告向法庭提出的实体请求 | 逐项列出 |
| 答辩意见 | 被告对请求的回应 | 承认 / 否认 / 抗辩结构 |
| 无争议事实 | 双方认可的事实 | 单独列表，供「经审理查明」参考 |
| 待查明事实 | 尚需证据或法律评价的事实 | 与争点对应 |
| 三性 | 真实性、合法性、关联性 | 质证小节使用 |
| 要点式庭审笔记 | 上海试点：复杂案件书记员笔记形式 | **本 Agent 输出定位** |
| 法庭笔录 | 具有法定形式的庭审记录 | Agent **不得** 声称已生成 |
| 音字转换 | ASR 同步转写文字 | 须核对签字后方具笔录效力 |
| 录音录像 | 全程庭审视听记录 | 法释〔2017〕5号全程要求 |
| 元数据记录表 | 庭审录音录像文件信息表 | 智慧庭审系统生成，Agent 不参与 |

## 禁止混用

- 「要点笔记」≠「正式笔录」
- 「归纳争点」≠「裁判主文」
- 「辅助稿」≠「已入卷材料」
