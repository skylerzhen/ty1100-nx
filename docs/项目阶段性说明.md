## 一、项目目标

在天数智芯 **TY1100-NX** 边端算力终端上，验证 **开源大模型本地推理性能**，并基于 **Pi（pi-coding-agent）** 搭建一套 **数据不出域** 的私有化 Agent 框架，服务于政务 / 国企 / 金融 / 医疗等 **禁止数据泄露** 场景。

核心思路：**本地模型 + 规则库（硬约束）+ 知识库（机构事实）**，Agent 主动拦截违规请求，合规请求在本地完成。

**技术选型说明：**

- Agent 底座：**Pi**（pi-coding-agent），非 OpenClaw
- 推理框架：llama.cpp（天数官方 Docker 镜像）
- 本地模型：Qwen3.6-35B-A3B Q4_K_M

## 二、硬件与推理性能（已实测）

| 项目 | 结果 |
|------|------|
| 设备 | TY1100-NX，Iluvatar MR-V100，32GB 显存 |
| CPU | 12 核 ARM64 |
| SDK | CoreX 4.4.0 |
| 模型 | Qwen3.6-35B-A3B，Q4_K_M（llama.cpp） |
| 推理 API | `http://127.0.0.1:8081/v1/chat/completions` |
| **输出速度** | **约 30 tokens/s**（与官方 vLLM 基准同量级） |
| 设备 IP | `192.168.34.9`（34 网段有线；Wi-Fi 44 网段不可达） |
| SSH | `ssh cix@192.168.34.9` |

**重要调用参数：** 请求须包含 `"chat_template_kwargs":{"enable_thinking":false}`，否则 Qwen3.6 输出会进入思维链字段，`content` 为空。

**推荐调用示例：**

```bash
curl -s http://127.0.0.1:8081/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"你好"}],"max_tokens":64,"chat_template_kwargs":{"enable_thinking":false}}'
```

详细数据见 [TY1100-NX_性能测试.md](./TY1100-NX_性能测试.md)。

## 三、Agent 架构

```
TY1100-NX 边端终端
├── llama.cpp（8081）              ← 本地大模型推理
├── Pi Agent（pi-coding-agent）  ← Agent 运行时
└── ~/ty1100-agent/              ← 项目目录
    ├── AGENTS.md                ← Agent 行为总纲
    ├── knowledge/               ← 知识库
    ├── rules/                   ← 规则库（防泄露硬约束）
    │   └── legal/               ← 法律庭审辅助规则包（含法律法规原文）
    ├── scripts/inspect.sh       ← 设备一键巡检
    └── .agents/skills/          ← 合规检查、庭审摘要、巡检 Skill
```

### 工作优先级（从高到低）

1. **`rules/legal/statutes/` 法律法规** — 最高优先级（法释〔2017〕5号等）；引用条文编号
2. **`rules/` 规则库** — 必须遵守；冲突时拒绝执行并引用规则编号（如 `[R-DLP-001]`）
3. **`knowledge/` 知识库** — 机构制度、设备信息、部署说明
4. **本地模型推理** — 仅 `127.0.0.1:8081`
5. **运维脚本** — `bash scripts/inspect.sh`（只读巡检，结果不得建议外发）

### 回答流程

1. 判断请求是否触及数据外传、跨境、公网 API、批量导出、L4/L5 内容、未经许可复制庭审录音录像
2. 命中 P0 规则 → **拒绝** + 规则编号 + 合规替代方案
3. 未违规 → 查知识库 → 本地模型生成回答
4. L3+ 内容 → 脱敏、摘要；末尾可注明「未使用公网服务」

## 五、规则库内容

### 5.1 通用合规规则（政务 / 企业）

| 规则文件 | 内容 | 优先级 |
|----------|------|--------|
| `00-priority.md` | 规则冲突与优先级 | P0 |
| `data-leakage-prevention.md` | 禁止公网 LLM、禁止整库导出、禁止跨境传输等 | P0 |
| `data-classification.md` | 数据分级 L1–L5，密级不明按最严处理 | P0 |
| `network-isolation.md` | 禁止暴露 SSH/API 到公网 | P0 |
| `gov-compliance.md` | 政务场景补充要求 | P1 |
| `enterprise-compliance.md` | 企业场景补充要求 | P1 |
| `audit-and-logging.md` | 审计留痕，禁止建议删日志 | P1 |
| `model-inference-boundary.md` | 推理仅限本地 8081 | P1 |
| `ops-rules.md` | 边端设备运维 | P2 |

**典型拒绝示例：**

| 用户请求 | Agent 行为 |
|----------|------------|
| 「帮我把客户名单发到 ChatGPT 分析」 | 拒绝，引用 `[R-DLP-001]`，建议本地 8081 脱敏摘要 |
| 「把知识库打包发邮箱」 | 拒绝，引用 `[R-DLP-003]` |
| 「把 SSH 映射到公网方便在家连」 | 拒绝，引用 `[R-NET-004]` |

### 5.2 法律庭审辅助规则包（上海法院示例）

**场景定位：** 法官在本地边端，从庭审对话 / 音字转换文本中 **提炼要点式庭审笔记**；**不替代** 法院智慧庭审系统的正式录音录像与笔录。

| 层级 | 文件 | 说明 |
|------|------|------|
| **法律法规原文** | `statutes/fabiao-2017-5-recording.md` | **法释〔2017〕5号** 全文 19 条 + Agent 适用要求 |
| | `statutes/shanghai-hshfy-pilot-2020.md` | 上海高院庭审记录改革试点要点 |
| | `statutes/fafa-2016-21-simplify.md` | 繁简分流相关条款 |
| **执行总纲** | `statutes-enforcement.md` | P0 拒绝清单 + 输出免责声明 |
| **场景规则** | `legal-ai-boundary.md` | AI 司法辅助边界 |
| | `legal-court-recording.md` | 庭审记录与录音录像规范 |
| | `legal-record-elements.md` | 必须提炼的庭审要素 |
| | `legal-party-privacy.md` | 当事人隐私保护 |
| | `legal-forbidden.md` | 法律场景禁止行为 |
| | `shanghai-court-recording.md` | 上海庭审记录改革对齐 |

**Agent 定位说明：**

| 层级 | 职责 |
|------|------|
| **正式层** | 法院智慧庭审系统（全程录音录像、区块链存证、元数据签字入卷） |
| **边端 Agent** | 要点式庭审笔记辅助稿，**不具有正式法庭笔录效力** |

**法律场景 P0 拒绝清单：**

| 编号 | 行为 |
|------|------|
| P0-1 | 未经许可录音录像、复制、删除、迁移庭审录音录像 |
| P0-2 | 将庭审内容上传公网/境外 AI |
| P0-3 | 声称 Agent 输出 = 正式法庭笔录 / 已签字入卷 |
| P0-4 | 建议不录音录像开庭 |
| P0-5 | 建议人为中断录音录像（法定三类除外） |
| P0-6 | 处理 L4/L5 涉密庭审内容并对外输出 |

**庭审辅助输出必备声明：**

> 本材料为本地 AI 辅助生成的要点式笔记（辅助稿），不具有正式法庭笔录效力；须依照法释〔2017〕5号及法院庭审记录改革规定，经审判人员、书记员、诉讼参与人核对签字后方可入卷使用。未使用公网服务。

## 七、部署方式

### 7.1 网络要求

- 须接 **34 网段** 有线口（如 PC `192.168.34.7`）
- Wi-Fi 为 **44 网段**（如 `192.168.44.105`），**无法访问** 设备
- 设备有两个网口，换口可能导致 IP 变化；当前设备 IP 为 `192.168.34.9`
- **勿将** `192.168.34.255` 用作主机 IP（广播地址）

### 7.2 Windows → 设备同步

```powershell
scp -r C:\Users\five0\Desktop\ty1100-nx\agent cix@192.168.34.9:~/
```

### 7.3 设备端安装

```bash
bash ~/agent/setup-ops-agent.sh
```

### 7.4 连接设备

```powershell
ssh cix@192.168.34.9
```

> 默认凭据仅用于内网测试，生产环境应修改密码。

### 7.5 Pi 本地模型配置

```bash
mkdir -p ~/.pi/agent
# 参考仓库 config/pi-models.json.example
sudo npm install -g --ignore-scripts @earendil-works/pi-coding-agent
```
