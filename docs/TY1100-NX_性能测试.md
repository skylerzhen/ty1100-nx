## 1. 测试目的

## 3. 测试方法

1. SSH 登录设备，执行 `ixsmi`、Docker 状态检查，确认 GPU 与服务可用。
2. 对 llama-server 发送 HTTP POST，记录 `timings` 与 curl 总耗时。
3. 分别测试默认请求（含思维链）与关闭思考模式（`enable_thinking: false`）两种场景。

**推荐生产调用方式：**

```bash
curl -s http://127.0.0.1:8081/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"你好，用50字介绍你自己"}],"max_tokens":128,"chat_template_kwargs":{"enable_thinking":false}}'
```

### 4.3 推理性能实测

#### 场景 A：默认模式（含思维链）

| 指标 | 实测值 |
|------|--------|
| Prompt | 18 tokens / 1142.6 ms（15.75 tokens/s） |
| 生成 | 128 tokens / 4160.6 ms |
| **Output TPS** | **30.76 tokens/s** |
| 端到端 | 5.43 s |

现象：`content` 为空，输出写入 `reasoning_content`；`finish_reason: length`（token 预算被思考过程占满）。

#### 场景 B：关闭思考（生产推荐）

| 指标 | 实测值 |
|------|--------|
| Prompt | 20 tokens / 594.6 ms（33.64 tokens/s） |
| 生成 | 42 tokens / 1386.0 ms |
| **Output TPS** | **30.30 tokens/s** |
| 回复 | `content` 正常返回中文自我介绍 |
| 结束原因 | `stop` |

#### 与官方基准对比

| 来源 | 框架 | 模型 | Output TPS |
|------|------|------|------------|
| 官方文档 | vLLM | Qwen3.6-35B-A3B-AWQ | 30.34 |
| 本次实测 | llama.cpp | Qwen3.6-35B-A3B Q4_K_M | **30.30～30.76** |

> 框架、量化格式、序列长度不同，为同量级参考对比，非严格同条件 benchmark。

## 5. 结论

1. **TY1100-NX 环境可用**：GPU、SDK、Docker 正常，SSH 可远程管理。
2. **35B 开源模型已部署且稳定**：Qwen3.6-35B-A3B（Q4_K_M）通过 8081 提供 OpenAI 兼容 API。
3. **推理性能达标**：生成吞吐约 **30 tokens/s**，与官方 vLLM 35B 基准（30.34 tokens/s）同量级。
4. **调用注意**：该模型为思考型变体，生产集成须关闭思考或解析 `reasoning_content`。
5. **Agent**：有部署基础（qwenpaw 镜像），本轮未测。

### 场景建议

| 场景 | 建议 |
|------|------|
| 本地大模型 API | 推荐，8081 可直接使用 |
| 35B 量化模型 | 可行 |
| 高并发 / 双模型 | 不推荐，显存余量约 4 GB |
| Agent 应用 | 待 qwenpaw 专项测试 |
