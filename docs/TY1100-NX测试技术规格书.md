## 3. 硬件规格（TY1100-NX）

### 3.1 核心算力

| 参数 | 规格 |
|------|------|
| AI 算力 | **130 TOPS @ INT8**（稠密） |
| CPU | 12 核 ARM（8×A720 + 4×A520，Armv9） |
| CPU 性能参考 | 整机超 300 KDmips |
| GPGPU | 天数自研，CUDA 生态兼容 |
| 算力架构 | GPGPU + NPU 异构 |

### 3.2 内存与存储

| 参数 | 规格 |
|------|------|
| 系统内存 | 16GB LPDDR5x |
| 显存 | **32GB / 64GB**（统一内存架构，视 SKU 而定） |
| 内置存储 | 512GB NVMe SSD（最大可扩 2TB） |
| SWAP | 出厂 16GB（一般无需调整） |

### 3.3 多媒体能力

| 参数 | TY1100-NX | 备注 |
|------|-----------|------|
| 视频编码 | 16 路 1080p@30fps（H.264/H.265/AVS2） | **支持硬件编码** |
| 视频解码 | 80 路 1080p@30fps（H.264/H.265/AVS2） | |
| 多媒体框架 | FFmpeg、GStreamer | |
| 硬件编解码 API | ixCODEC | 详见《软件栈API参考_V4.4.0.pdf》 |

> **与 NX-PRO 差异：** TY1100-NX-PRO（230 TOPS）解码 128 路，但 **不支持硬件编码**；NX 支持编解码。

### 3.4 网络与无线

| 参数 | 规格 |
|------|------|
| 有线网络 | 2× 千兆以太网（RJ45） |
| 无线扩展 | 支持 Wi-Fi 6E / BT / 5G / 4G（需加装模组） |
| EtherCAT | 2× RJ45（部分型号配置） |

### 3.5 物理规格

| 参数 | 规格 |
|------|------|
| 尺寸 | 135 × 135 × 63 mm |
| 功耗（典型） | < 95W |
| 工作温度 | 0°C ~ 50°C |
| 存储温度 | -10°C ~ 55°C |

### 3.6 与同系列型号对比

| 型号 | 形态 | 算力 | 显存 | 编码 | 解码 |
|------|------|------|------|------|------|
| TY1000 | 模组 699Pin | 200 TOPS | 16GB HBM2e | 16 路 | 96 路 |
| TY1100 | 模组 699Pin | 230 TOPS | 16GB HBM2e | 16 路 | 128 路 |
| **TY1100-NX** | **终端** | **130 TOPS** | **32/64GB** | **16 路** | **80 路** |
| TY1100-NX-PRO | 终端 | 230 TOPS | 32GB HBM2e | 不支持 | 128 路 |
| TY1200 | 终端 x86 | 300 TOPS | 32GB HBM2e | 16 路 | 204 路 |

## 5. 软件栈规格

### 5.1 操作系统

| 项目 | 规格 |
|------|------|
| 预装系统 | Debian 12（精简版） |
| 内核版本 | 6.6.89 |
| 默认用户 | `cix` |
| 默认密码 | `cix` |
| 可选系统 | Ubuntu 22.04、OpenKylin、OpenEuler（需联系天数） |

### 5.2 版本标识

| 组件 | 版本 | 查看方式 |
|------|------|----------|
| SSD 镜像 | **SSD_V_2.4.0** | `cat /etc/iluvatar-release` |
| 算力 SDK | **4.4.0** | `ixsmi` |
| SDK 安装路径 | `/usr/local/corex` | |
| CUDA 兼容 | CUDA 10.2 工具链 | |

**验收标准：** SSD ≥ 2.4.0，SDK = 4.4.0。低于此版本建议升级。

### 5.3 AI 框架与生态

| 类别 | 支持项 |
|------|--------|
| 深度学习框架 | PyTorch、TensorFlow、PaddlePaddle、ONNX Runtime |
| 推理引擎 | IGIE、ixRT、TensorRT（兼容） |
| 加速库 | ixDNN、ixBLAS、ixFFT、ixFormer、ixSPARSE 等 |
| 流媒体 | GStreamer、DeepStream、IxStream |
| 机器人 | ROS 各版本 |
| 容器化 | Docker（**官方强烈推荐**） |

### 5.4 天数适配 Python 包识别

执行 `pip show <package>` 或 `pip list | grep corex`，版本信息含 **`corex`** 关键字为天数的适配包，**不可在线覆盖安装**。

**约束：** `numpy` 版本须 **< 2.0**（推荐 `numpy==1.26.4`）。

支持码流格式：**H.264、H.265、AVS2、VP9**。

## 8. 官方 Benchmark 测试用例与预期指标

### 8.1 大模型推理（vLLM）

**测试镜像：** `poc-llm-infer:v1.2.5-ty1100-4.4.0`

**推荐模型（ModelScope）：**

| 模型 | 下载路径 | NX 显存建议 |
|------|----------|-------------|

**通过标准：** 测试结果与文档基准偏差应在合理范围内（建议 ±10%，以项目要求为准）。

## 9. 应用场景与能力边界（测试参考）

| 场景 | NX 适用性 | 关键指标 |
|------|-----------|----------|
| 本地多路视频分析 | ✅ 适合 | 80 路解码 |
| 机器人导航 + 运动控制 | ✅ 适合 | 130 TOPS，ROS |
| 轻量大模型推理 | ✅ 适合 | 27B 量化 / 35B 量化 |
| 私有化 Agent | ✅ 适合 | 9B~27B 本地 |
| 35B 级大模型（非量化） | ❌ 不适合 | 需 TY1200 |
| 具身智能 VLA 大模型 | ⚠️ 受限 | 建议 NX-PRO / TY1200 |

**大模型本地部署上限（产品宣传）：** 可支持约 **35B-A3B** 级模型本地部署（量化）。
