## 一、项目是什么

### 1.1 一句话说明

在 **天数智芯 TY1100-NX** 边端 AI 硬件上，搭建本地运行环境，部署并验证 **AI 应用**（可离线、不依赖云端）。

### 1.2 项目架构

```
硬件层    TY1100-NX（国产 GPGPU + ARM CPU）
   ↓
系统层    Debian 12 + 天数 CoreX SDK（/usr/local/corex）
   ↓
容器层    Docker + 官方预置镜像（强烈推荐）
   ↓
应用层    大模型 / Agent / 视频分析 / 目标检测 等
```

### 1.3 这不是什么

- 不是普通纯软件 Web 项目
- 不是只在 Windows 笔记本上写代码即可
- 核心工作发生在 **TY1100 设备本机**（通过 SSH 或直连显示器操作）

### 1.4 可选应用场景（需与导师/团队确认一项）

| 场景 | 推荐镜像 | 说明 |
|------|----------|------|
| 私有化 Agent 办公助手 | openclaw | 本地 Qwen，浏览器访问 |
| 本地大模型推理 | vllm | Qwen3.6 等量化模型 |
| 视频分析 / 多路监控 | ixstream | GStreamer + 目标检测 |
| YOLO 等 CV 检测 | deepsparkinference | IGIE / IXRT 推理引擎 |
| 机器人 / SLAM | 联系天数工程师 | 需专有镜像 |

**未定场景前，建议先跑通 Agent 或 YOLO Demo 验证算力。**

## 四、连接设备（阶段 0 · 当前重点）

> **一切后续工作的前提：必须先能登录 TY1100。**

### 4.1 三种连接方式对比

| 方式 | 接线 | 优点 | 缺点 |
|------|------|------|------|
| **A. 经路由器** | TY1100 → 路由器 LAN；笔记本 Wi‑Fi | 可上网、易找 IP | 路由器需能发现设备 |
| **B. 直连笔记本** | TY1100 → 笔记本网口 | 不依赖路由器 | 需手动配 IP / 共享网络 |
| **C. HDMI + 键盘** | 显示器接 TY1100 | 最可靠、可本机操作 | 需外接显示器/电视 |

**笔记本自带屏幕不能作为 TY1100 的显示器**（HDMI 为输出口，非输入）。

### 4.2 方式 A：经路由器（推荐）

```
TY1100 ──网线──► 路由器 LAN 口（不是 WAN）
笔记本 ──Wi‑Fi──► 同一路由器
```

1. 设备开机，等待 2～3 分钟
2. 浏览器打开 `http://192.168.1.1`（以本机 `ipconfig` 默认网关为准）
3. 查看「网线连网设备」，找新出现的设备（可能名为 `cix`、`debian`、`*`）
4. 或在 PowerShell 扫描 SSH 端口：

```powershell
1..254 | ForEach-Object {
  $ip = "192.168.1.$_"
  $r = Test-NetConnection $ip -Port 22 -WarningAction SilentlyContinue
  if ($r.TcpTestSucceeded) { Write-Host "SSH open: $ip" }
}
```

5. 连接：

```powershell
ssh cix@设备IP
# 提示 yes/no → 输入 yes
# 密码 → cix
```

**注意：** `192.168.1.105` 若显示为 `DESKTOP-xxx`，是 Windows 电脑，不是 TY1100。

### 4.3 方式 B：直连笔记本

```
TY1100 ──网线──► 笔记本网口（不经过路由器）
```

#### 步骤 1：设置笔记本以太网 IP

1. `Win + R` → `ncpa.cpl` → 回车
2. 以太网 → 属性 → IPv4 → 使用下面的 IP：

| 项目 | 值 |
|------|-----|
| IP 地址 | 192.168.7.1 |
| 子网掩码 | 255.255.255.0 |
| 默认网关 | 留空 |

#### 步骤 2：启用 Wi‑Fi 共享（推荐）

1. WLAN → 属性 → **共享**
2. 勾选「允许其他网络用户通过此计算机的 Internet 连接来连接」
3. 选择 **以太网**
4. 等待 1～2 分钟，设备可能获得 `192.168.137.x`

```powershell
arp -a
ping 192.168.137.2
ssh cix@192.168.137.2
```

#### 步骤 3：判断网线是否接通

打开 `ncpa.cpl` 查看以太网状态：

| 状态 | 含义 |
|------|------|
| 网络电缆被拔出 | 线未通，换线/换口/插紧 |
| 未识别的网络 | 线可能已通，继续配 IP / 共享 |

#### 步骤 4：其他可试 IP

- 两个网口都试
- 以太网改「自动获得 IP」后看 `169.254.x.x`（`arp -a`）
- 对 ARP 中出现的 IP 逐个 `ssh cix@IP`

### 4.4 方式 C：HDMI + 键盘

1. HDMI 接电视/显示器，USB 键盘接 TY1100
2. 登录 `cix` / `cix`
3. 终端执行：

```bash
ip addr
ixsmi
```

4. 笔记本在同一网络 SSH：`ssh cix@设备IP`

### 4.5 方式 D：问设备提供方

若以上均失败，联系给设备的人确认：

- 默认 IP 是否固定？
- 密码是否仍为 `cix/cix`？
- 首次是否必须用 HDMI 激活？
- 是否有预配置文档？

## 八、常见问题

### Q1：Windows 上运行 `ifconfig` 报错？

`ifconfig` 是 Linux 命令。Windows 用 `ipconfig`；在 TY1100 上才用 `ifconfig` 或 `ip addr`。

### Q2：SSH 提示 Permission denied？

- 可能连错了设备（如连到了 `DESKTOP-xxx` 的 192.168.1.105）
- 密码错误：确认 `cix` / `cix`，注意 Caps Lock
- 联系设备提供方确认密码是否被修改

### Q3：路由器里找不到 TY1100？

- 确认插在 **LAN 口** 而非 WAN
- 等 2～3 分钟再刷新
- 用 SSH 端口扫描代替路由器界面
- 或改 HDMI / 直连 / 问厂商

### Q4：直连 ping 不通 192.168.7.2？

设备不会自动使用该 IP。试 Wi‑Fi 共享（192.168.137.x）或自动 IP（169.254.x.x），或需 HDMI 在本机配置网络。

### Q5：需要重装 SDK 吗？

一般 **不需要**。设备预装 SDK 4.4.0，`ixsmi` 正常即可。仅当版本过旧或损坏时参考文档「算力软件栈安装」。

### Q6：开发一定要用 Docker 吗？

文档 **强烈建议** 使用官方 Docker 镜像，可避免手动配 Python、CUDA 兼容库等环境问题。

## 九、Windows 常用命令速查

```powershell
# 查看本机 IP 和网关
ipconfig

# 测试连通
ping 192.168.1.xxx

1..254 | ForEach-Object {

```
